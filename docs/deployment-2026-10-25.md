## Оставшаяся проверка сети

У реально запущенного прежнего сервиса TURN_URL/TURN_SECRET отсутствовали.
На VPS также не обнаружены coturn/turnserver и слушающие 3478/5349.
После обновления конфигурация сохраняет существующие параметры:
`voiceLimit=6`, `iceTransportPolicy=all`, TURN не настроен.

Принудительный relay нельзя считать проверенным: работающего TURN нет.
Для надёжной связи между разными NAT требуется отдельная настройка TURN,
затем проверка двух физических компьютеров в разных сетях и relay candidate.
Без этого обновление кода не гарантирует устранение тишины в любой сети.

После обновления обе страницы необходимо полностью перезагрузить, при
необходимости Ctrl+F5; старые открытые страницы не поддерживают membershipId.
Для E2EE комнаты название и секрет должны совпадать; код сверки одинаковый.

## Точный откат

Прежний checkout и его исходники сохранены. Для возврата web-сервиса:

```bash
sudo rm -- /etc/systemd/system/coroutine-chat-web.service.d/90-voice-release.conf
sudo systemctl daemon-reload
sudo systemctl restart coroutine-chat-web.service
systemctl is-active coroutine-chat-web.service coroutine-chat-tcp.service
```

Эти команды удаляют только созданный deployment drop-in. Данные и старый код
не удаляются; C++ сервер не перезапускается. После отката обновить страницы.
При дальнейших изменениях systemd сначала проверить актуальность этой инструкции.
